首个公开版本，提供 macOS 分享扩展，用于保存微信合并转发的聊天记录 ZIP。

## 下载

- `微信记录-0.1.0.dmg`
- `微信记录-0.1.0.dmg.sha256`

SHA-256：`6e2c8fc71844566e94f0b027e1643e4d59235d834f8d1bf6d457fbfc1a93a1a1`

## 安装

1. 下载 DMG 和校验文件，放在同一目录。
2. 运行 `shasum -a 256 -c 微信记录-0.1.0.dmg.sha256` 校验安装包。
3. 打开 DMG，将 `微信记录.app` 拖入 `Applications`。
4. 完全退出微信并重新打开。
5. 在微信中选择“合并转发”，再选择“其他应用”中的“微信记录”。

## 系统要求

- macOS 14 或更新版本。
- 微信 macOS。分享入口已在微信 4.1.13 上验证。

## 说明

- 存档保存到 `~/Downloads/聊天存档/`。
- 应用只处理用户主动分享的文件，不读取微信数据库，不上传文件。
- 安装包使用本地 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证。Gatekeeper 可能阻止首次启动。
