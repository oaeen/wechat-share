# Lucide Icons

图标来自 [Lucide Static](https://unpkg.com/lucide-static@1.80.0/)，版本 `1.80.0`，许可证 ISC。

应用图标使用 `message-square-share`，界面图标使用同一套 Lucide 线性图标：

- `message-square-share`
- `message-square-text`
- `share-2`
- `copy`
- `check`
- `trash-2`
- `folder-open`
- `triangle-alert`
- `file-archive`
- `file-text`
